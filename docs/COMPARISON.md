# atomcode vs Alternatives

| Feature | atomcode | Claude Code | Codex | OpenCode |
|---|---|---|---|---|
| License | MIT | proprietary | proprietary | MIT |
| Language | Rust | internal | internal | TS |
| Local LLM | yes | no | no | yes |
| Tool plugins | MCP | MCP | limited | MCP |
| Telemetry | opt-in | on | on | opt-in |

## Why atomcode
- True open source: audit everything, own your binary
- Runs fully offline with local LLMs
- Single static binary, <30MB memory idle
