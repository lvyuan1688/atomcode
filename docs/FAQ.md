# FAQ

## Is atomcode free?
Yes, MIT licensed. No telemetry, no paid tier.

## Does it work offline?
Yes, with local LLMs via Ollama or any OpenAI-compatible endpoint.

## How is it different from Claude Code?
atomcode is open-source Rust, you own the binary. Same agentic loop, tool dispatch, verify cycle.

## Windows support?
Yes, tested on Windows 10/11. Install via scripts/install.ps1.
