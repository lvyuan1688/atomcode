# Release Cadence

## Patch (v0.1.x)
- Bug fixes, docs, chore
- As needed, no schedule

## Minor (v0.X.0)
- New features, no breaking changes
- Monthly target

## Major (vX.0.0)
- Breaking changes allowed
- When accumulated minors warrant

## Support window
- Latest minor: active maintenance
- Prior minor: security fixes only
- Major-1: no support
