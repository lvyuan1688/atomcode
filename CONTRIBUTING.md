# Contributing to atomcode

First off, thank you for considering contributing to atomcode! 

## Active Maintainer

This fork is actively maintained by **lvyuan1688** (lvyaoyuan168@gmail.com).
All PRs and issues are reviewed by the maintainer.

## How to Contribute

1. **Fork** the repository to your own GitHub account
2. **Create a feature branch**: `git checkout -b feat/your-feature`
3. **Commit your changes** following Conventional Commits
4. **Push** to your fork and open a Pull Request against `main`
5. **Address review feedback** from the maintainer

## Code Style

- Rust 2021 edition
- `cargo fmt` before committing
- `cargo clippy` must pass without warnings

## Reporting Issues

Open a GitHub issue with:
- Clear title and description
- Reproduction steps (if applicable)
- Expected vs actual behavior
- Environment (OS, Rust version, atomcode version)

## Release Process

Releases are managed by the maintainer (lvyuan1688) following semantic versioning.
